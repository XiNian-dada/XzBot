推荐阅读顺序

如果你是第一次接触这个项目，建议按这个顺序走

  1. 先看 从零部署，把机器人跑起来。
  2. 再看 NapCat 对接，确认消息链路真的通了。
  3. 然后看 配置详解，把真实模型、搜索、OCR 配上。
  4. 接着看 网页控制台，以后日常维护会轻松很多。
  5. 最后再看 插件系统 和 升级与发版。
如果你只是想先确认链路能跑，先把 [ai].provider 设成 mock。这个建议非常省时间。
