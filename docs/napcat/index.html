OneBot v11 Reverse WS

NapCat 应该怎么接到 XzBot

这个项目只依赖 NapCat 的 OneBot v11 反向 WebSocket（WS 客户端）。也就是说：NapCat 主动连 XzBot，XzBot 自己监听。

1. NapCat 里应该开哪一个

能力要不要开说明
OneBot v11必须开这是协议基础。
WS 客户端 / 反向 WS必须开XzBot 标准接入方式。
WS 服务端通常不用除非你还有别的系统依赖它。
HTTP 上报通常不用XzBot 不依赖它。

2. 地址怎么填

ws://你的服务器IP:3000/onebot/v11/ws

其中：

  • 3000 来自 [server].port
  • /onebot/v11/ws 来自 [server].ws_path

3. 如果开了 token 校验怎么办

如果你把：

[server]
verify_token = true
access_token = "你的token"

那 NapCat 里也要把同一个 token 配进去，不然连接会被拒绝。

4. 最稳的排查顺序

  1. 先确认 NapCat 的反向 WS 已经启用。
  2. 确认连接地址是你当前 XzBot 真正在监听的地址。
  3. 确认本机 / 服务器防火墙没有拦截端口。
  4. 如果开了 token，确认两边 token 一模一样。
如果你已经能看到 XzBot 控制台里有新的群消息事件进来，那 NapCat 这一层基本就通了。
