Plugin Host Platform

后续新功能，尽量优先走插件

现在 XzBot 的插件系统已经支持：

  • 命令型插件
  • 事件型插件
  • AI 工具注册
  • 多动作输出
  • stop_propagation 阻断默认处理

1. 为什么推荐新功能做成插件

  • 主程序职责更稳
  • 业务功能出问题时边界更清楚
  • 插件目录可以带自己的配置、状态和输出

2. 插件目录应该怎么放

Plugins/
  XzPaper-plugin
  XzPaper/
    config.toml
    state.json
    output/
      ...

3. 插件最常见的三种模式

  1. 命令插件：例如 /analyze
  2. 事件插件：例如监听群消息、图片、引用、mention
  3. 工具插件：把自定义 function call 注册给 AI

4. 文档进一步看哪里
