1. 主配置和覆盖文件

最推荐的使用姿势是：

  • 先只改 config/config.toml
  • 某一块变长了，再拆到 persona.toml / ai.toml / network.toml
  • 拆出去的覆盖文件顶层要改成 enabled = true
# config/persona.toml
enabled = true

[persona]
system = """
这里放长人设
"""

2. AI 与模型接入

常见的几种配法：

[ai]
provider = "openai_compatible"
base_url = "https://your-gateway.example/v1"
api_key = "sk-xxx"
model = "gpt-5.4"
fallback_models = ["gpt-4.1", "gpt-4o-mini"]

如果你的网关走 /responses：

[ai]
wire_api = "responses"

如果你的网关在 chat/completions 下必须 stream=true 才正常返回正文：

[ai]
wire_api = "chat_completions"
stream_chat_completions = true

3. 搜索与抓取

[search]
provider = "builtin"   # 或 "searxng"
searxng_url = ""

如果你启用了 SearXNG，就会优先走你自己的搜索实例。知乎链接则会优先构造公开 API，而不是硬撞网页壳页面。

4. OCR 与图片

多模态模型会直接看图，纯文本模型才会退回 OCR。支持本地 Tesseract 或 Paddle OCR：

[ai]
vision_mode = "auto"
ocr_provider = "tesseract"
ocr_cmd = "tesseract"
ocr_lang = "chi_sim+eng"

5. 代理

[network]
proxy_enabled = true
proxy_url = "socks5://127.0.0.1:10808"
proxy_test_url = "https://www.google.com"
proxy_timeout_ms = 10000

如果只想让 Paddle OCR 直连，可以把 paddle_use_proxy = false。

6. 网页控制台配置

[web_admin]
enabled = true
token = "请换成强随机 token"
title = "XzBot Console"
现在控制台已经支持：核心配置编辑、日志查看、插件概览、插件文件管理器、保存后热重载。
