Web Console

如果你觉得手改 TOML 麻烦，直接用这个面板

1. 怎么开启

[web_admin]
enabled = true
token = "请换成你自己的强随机 token"
title = "XzBot Console"

访问：

http://你的服务器IP:3000/admin

2. 现在能做什么

  • 查看当前 Provider / Model / WS 状态
  • 编辑核心配置和覆盖文件
  • 自动刷新的日志页
  • 查看插件、命令、事件订阅、工具
  • 在插件页用“文件管理器”方式编辑插件文本文件
  • 保存并热重载

3. 哪些改动不能只靠热重载生效

像下面这些监听配置，通常要重启进程才会完全生效：

  • server.host
  • server.port
  • server.ws_path

4. 插件页为什么单独做文件管理器

因为插件目录里不一定只有“配置文件”，还会有状态文件、缓存文件、输出文件。如果把它们全混到“配置页”里，就会很乱。现在插件文件已经被单独放到插件页处理了。

控制台仍然只是“磁盘文件的图形化入口”，没有引入第二套配置源。你在页面里保存，本质上还是写回原来的 TOML 或插件文本文件。
