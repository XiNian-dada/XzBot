FAQ

最常卡住的地方，都在这了

1. 启动时报 Address in use

说明端口被旧进程占用。先停掉旧进程，或者换 server.port。

2. NapCat 连不上 XzBot

  • 先确认你开的是“WS 客户端 / 反向 WebSocket”
  • 确认地址是 ws://你的IP:端口/ws_path
  • 如果开了 token 校验，确认两边 token 完全一致

3. 群里发了上一条消息，Bot 却说看不到

现在最近群聊上下文已经改成了按需工具查询，效果比以前稳，但如果你想让它百分百理解某条具体消息，最稳的方式还是：直接引用那条消息。

4. 控制台打不开

  • 确认 [web_admin].enabled = true
  • 确认你访问的是当前机器人监听的端口
  • 确认你运行的是带控制台代码的新二进制

5. 某些模型网关 curl 能回，Bot 却报空内容

这通常是兼容网关要求 stream=true，可以试：

[ai]
wire_api = "chat_completions"
stream_chat_completions = true
